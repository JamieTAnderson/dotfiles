Neovim plugin list

Plugins are managed by lazy.nvim.
Pinned plugin versions live in lazy-lock.json.

1. folke/lazy.nvim
   Purpose: Bootstraps and manages all plugins.
   Useful command: :Lazy
   Config: lua/config/lazy.lua

2. folke/tokyonight.nvim
   Purpose: Provides the colorscheme loaded at startup.
   Config: lua/plugins/colorscheme.lua

3. folke/which-key.nvim
   Purpose: Shows available keybindings after pressing a prefix like <leader>.
   Config: lua/plugins/which-key.lua

4. nvim-telescope/telescope.nvim
   Purpose: Fuzzy finder for files, text search, buffers, and help tags.
   Config: lua/plugins/telescope.lua
   Keymaps:
     <leader>ff finds files.
     <leader>fg searches text with live grep.
     <leader>fb lists open buffers.
     <leader>fh searches help tags.

5. nvim-lua/plenary.nvim
   Purpose: Utility library required by Telescope and Neo-tree.
   Config: lua/plugins/telescope.lua and lua/plugins/neo-tree.lua

6. lewis6991/gitsigns.nvim
   Purpose: Shows Git changes in the sign column.
   Config: lua/plugins/git.lua

7. hrsh7th/nvim-cmp
   Purpose: Completion menu engine.
   Config: lua/plugins/completion.lua
   Keymaps:
     <C-Space> opens completion.
     <C-e> closes completion.
     <CR> confirms the selected completion.
     <Tab> selects the next completion item or jumps through a snippet.
     <S-Tab> selects the previous completion item or jumps backward through a snippet.

8. hrsh7th/cmp-nvim-lsp
   Purpose: Adds LSP completion results to nvim-cmp.
   Config: lua/plugins/completion.lua and lua/plugins/lsp.lua

9. hrsh7th/cmp-buffer
   Purpose: Adds words from the current buffer to completion.
   Config: lua/plugins/completion.lua

10. hrsh7th/cmp-path
    Purpose: Adds filesystem paths to completion.
    Config: lua/plugins/completion.lua

11. L3MON4D3/LuaSnip
    Purpose: Snippet engine used by completion.
    Config: lua/plugins/completion.lua

12. saadparwaiz1/cmp_luasnip
    Purpose: Connects LuaSnip snippets to nvim-cmp.
    Config: lua/plugins/completion.lua

13. windwp/nvim-autopairs
    Purpose: Automatically inserts matching closing characters for pairs like (), [], {}, quotes, and backticks.
    Config: lua/plugins/autopairs.lua

14. neovim/nvim-lspconfig
    Purpose: Provides LSP server configuration defaults.
    Config: lua/plugins/lsp.lua

15. mason-org/mason.nvim
    Purpose: Installs external language servers and developer tools.
    Useful command: :Mason
    Config: lua/plugins/lsp.lua

16. mason-org/mason-lspconfig.nvim
    Purpose: Connects Mason-installed language servers to Neovim LSP.
    Config: lua/plugins/lsp.lua

17. nvim-treesitter/nvim-treesitter
    Purpose: Installs Treesitter parsers and query files for syntax highlighting and indentation.
    Useful command: :TSInstallConfigured
    Config: lua/plugins/treesitter.lua

18. nvim-neo-tree/neo-tree.nvim
    Purpose: Provides a sidebar file explorer with filesystem, buffer, and Git status views.
    Useful command: :Neotree
    Config: lua/plugins/neo-tree.lua
    Keymaps:
      <leader>n toggles the file explorer.
      <leader>nf reveals the current file.
      <leader>ng opens the Git status view.
      <leader>nb opens the buffer view.

19. MunifTanjim/nui.nvim
    Purpose: UI components required by Neo-tree.
    Config: lua/plugins/neo-tree.lua

20. nvim-tree/nvim-web-devicons
    Purpose: Filetype icons used by Neo-tree.
    Config: lua/plugins/neo-tree.lua

21. pi-inline.nvim
    Purpose: Asks the Pi coding agent questions from Neovim and can apply Pi-provided diffs to the current buffer.
    Useful command: :Pi
    Config: lua/plugins/pi-inline.lua
    Keymaps:
      <leader>pp opens Pi Inline.
      <leader>pc clears Pi Inline ghost text.
      <leader>pC cancels the active Pi request.
      <leader>ps selects a Pi session.
      <leader>pS clears the selected Pi session.

22. ThePrimeagen/99
    Purpose: Provides AI-assisted project search and visual-selection workflows from Neovim.
    Config: lua/plugins/primeagen-99.lua
    Provider: OpenCode with model openai/gpt-5.5.
    Keymaps:
      <leader>9s asks 99 to search the project.
      <leader>9v asks 99 about the current visual selection.
      <leader>9x stops active 99 requests.

Configured LSP servers:

1. lua_ls for Lua.
2. ts_ls for TypeScript and JavaScript.
3. pyright for Python.
4. gopls for Go.
5. rust_analyzer for Rust.
6. bashls for Bash.
7. jsonls for JSON.
8. yamlls for YAML.

gopls is only auto-installed when the go executable is available.

Useful commands:

1. :PluginDocs opens this plugin inventory.
2. :Lazy manages plugins.
3. :Mason manages language servers and external tools.
4. :TSInstallConfigured installs the configured Treesitter parsers.
5. :checkhealth checks Neovim and plugin health.
6. :Neotree opens Neo-tree.
7. <leader>n toggles Neo-tree.
8. :Pi opens Pi Inline.
9. <leader>pp opens Pi Inline.
10. <leader>9s asks 99 to search the project.
11. <leader>9v asks 99 about a visual selection.
12. <leader>9x stops active 99 requests.
